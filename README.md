# Provenir Dashboard Mockup

Static HTML/CSS/JS prototype that recreates the provided dashboard style and packages it as a small multi-page sidebar navigation demo.

The root `.html` files are generated by the `DashboardShell` module source in `src/dashboard_shell/`.

## Files

```text
.
├─ applications.html
├─ integrations.html
├─ alerts.html
├─ workspaces.html
├─ index.html
├─ services.html
├─ creditcard-service.html
├─ style.css
├─ CONTEXT.md
└─ assets/
   ├─ fonts/
   ├─ icons/
   ├─ images/
   └─ js/

Source and build:

```text
src/
└─ dashboard_shell/
   ├─ template.html
   ├─ icon-sprite.html
   ├─ pages.json
   └─ partials/

scripts/
└─ build_dashboard_shell.py
```
```

## Run

Open `index.html` directly in a browser. The sidebar links navigate to the other static HTML pages.

To rebuild generated pages after editing shell sources:

```bash
python scripts/build_dashboard_shell.py
```

## Notes

- Fonts are local under `assets/fonts/`.
- The reusable icon source sprite lives in `assets/icons/sprite.svg`.
- All generated pages now share one global stylesheet: `style.css`.
- Each generated page keeps an inline runtime sprite so icons work correctly when opened via `file://`.
- Card selection behavior is in `assets/js/main.js`.
- Tree toggle behavior is also in `assets/js/main.js`.

## Extend

- Add future screenshots or exported UI assets to `assets/images/`.
- Move repeated page sections into components if you later migrate this mockup into a framework.
