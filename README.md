# Provenir Dashboard Mockup

Static HTML/CSS/JS prototype that recreates the provided dashboard style and packages it as a small multi-page sidebar navigation demo.

The root `.html` files are generated by the `DashboardShell` module source in `src/dashboard_shell/`.

## Files

```text
.
├─ applications.html
├─ alerts.html
├─ creditcard-service.html
├─ index.html
├─ integrations.html
├─ services.html
├─ workspaces.html
├─ style.css
├─ CONTEXT.md
├─ README.md
└─ assets/
   ├─ fonts/
   ├─ icons/
   ├─ images/
   └─ js/
      ├─ controllers/
      └─ pages/
```

Source and build:

```text
src/
└─ dashboard_shell/
   ├─ entity-cards.json
   ├─ header-addons.json
   ├─ template.html
   ├─ icon-sprite.html
   ├─ pages.json
   ├─ tree-menus.json
   └─ partials/

scripts/
├─ build_dashboard_shell.py
└─ dashboard_shell_build/
   ├─ context.py
   ├─ entity_cards.py
   ├─ header_addons.py
   ├─ output_writer.py
   ├─ page_specs.py
   ├─ shell.py
   └─ tree_menus.py
```

Generated pages are built from structured data and renderer modules:

- `DashboardShell` owns the shared app chrome
- `EntityCard` owns repeated catalog card rendering
- `TreeMenu` owns nested workbench tree rendering
- `HeaderAddon` owns header variations such as stage bars and toolbars
- `PageSpec` selects page-type renderers like `CardGridPage`, `ServiceListPage`, and `WorkbenchPage`

## Run

Open `index.html` directly in a browser. The sidebar links navigate to the other static HTML pages.

To rebuild generated pages after editing shell sources:

```bash
python scripts/build_dashboard_shell.py
```

## Notes

- Fonts are local under `assets/fonts/`.
- The reusable icon source sprite lives in `assets/icons/sprite.svg`.
- All generated pages now share one global stylesheet: `style.css`.
- Each generated page keeps an inline runtime sprite so icons work correctly when opened via `file://`.
- Card selection behavior lives in `assets/js/controllers/card-selection-controller.js` and is loaded by `assets/js/pages/card-grid-page.js`.
- Tree toggle behavior lives in `assets/js/controllers/tree-toggle-controller.js` and is loaded by `assets/js/pages/creditcard-service-page.js`.

## Extend

- Add future screenshots or exported UI assets to `assets/images/`.
- Add new page data in `src/dashboard_shell/pages.json` and extend the renderer modules when a new page type appears.
- Move to a framework only if you need runtime state or richer client-side seams than the static generator provides.
